1. Widoczność statusu systemu

Pierwsza heurystyka Jakoba Nielsena

Oryginalna treść (EN)

The design should always keep users informed about what is going on, through appropriate feedback within a reasonable amount of time.

```

Tłumaczenie (PL)

System powinien zawsze informować użytkowników o tym, co się dzieje, przekazując odpowiednią informację zwrotną w rozsądnym czasie.

```

Przykład ze strony internetowej

```

Pasek postępu pokazuje użytkownikowi, ile operacji zostało już wykonane. Dzięki temu użytkownik wie, że system działa poprawnie i nie zawiesił się.

Źródło: Wikimedia Commons – Progress Bar

```

Przykład z aplikacji mobilnej

```

Animowany wskaźnik ładowania informuje użytkownika, że aplikacja wykonuje operację i należy chwilę poczekać. Jest to przykład ciągłego informowania o stanie systemu.

Źródło: Wikimedia Commons – Loading Icon

```
